# DeepSleepRoutine

대학생들의 규칙적인 수면 습관 형성을 돕는 **나이트 루틴 플래너** 웹 프로젝트입니다.

## 주요 기능 (4페이지 구성)
- **오늘 루틴 (`index.html`)**: 매일 밤 실천하는 기본 수면 루틴 체크리스트 및 실시간 달성률 표시
- **수면 계산기 (`sleep-calc.html`)**: 내일 첫 수업 시간 기준 90분 수면 주기 추천 취침·기상 시간 계산
- **상황별 루틴 (`situation.html`)**: 시험·과제 후, 카페인 섭취, 1교시 전날 등 상황별 루틴 추천 및 오늘 루틴 추가
- **주간 기록 (`record.html`)**: 날짜별 루틴 달성률 기록 확인

## 사용 기술
- HTML, CSS, JavaScript (`localStorage` 기반 데이터 연동)

## 팀원 역할
- **1번**: 기획 · 메인(`index.html`) · 파일 합치기
- **2번**: 계산기(`sleep-calc.html`) · 데이터(`localStorage`)
- **3번**: 상황별 루틴(`situation.html`) · 공통 `style.css`
- **4번**: 기록(`record.html`) · 발표 PPT
